# 苔原契约 · Verdant Pact

React 19 + TypeScript + Vite 构建的单人卡牌 Web 原型。无需后端。深苔绿战术桌面、原创 SVG 生物徽记，适配桌面和窄屏。

## 运行

```sh
npm install
npm run dev
```

```sh
npm test       # Node.js 22.6+，核心战斗和印记规则测试
npm run build # TypeScript 检查及生产构建
npm run lint
```

## 冒险地图

从地图开始，18 层主进程，精英支线额外奖励节点。费用/种族拿牌采用两阶段三选一；强化可连续三轮，风险依次为 0、1/6、1/3。详细规则见 [冒险流程](docs/adventure.md)。Boss 胜利通关，战败结束本局。

## 试玩

- 选择手牌，标记己方场上单位献祭，每张默认提供 1 费。凑够费用前可撤销标记或取消；凑够且有落点时立即支付献祭，随后必须选择空位部署，不能取消、换牌或结束回合。0 费单位跳过献祭。
- 松鼠为 0 攻 / 1 血、0 费。起手 5 张主牌加 1 张松鼠，独立松鼠牌堆共 10 张（起手后剩 9 张）。每回合可从主牌堆或松鼠牌堆抽取 1 张，共享次数且不累积；不再自动抽牌。
- 战场占据屏幕中央，手牌在底部居中，必要状态与操作位于两侧。右键手牌或场上生物可查看印记说明；关闭说明会保留当前选牌。触屏可选择手牌后使用“查看印记”，场上卡片也支持点击查看。
- 场上卡和手牌统一为 3:4，共用卡面排版。镜头默认居中，在“敌方—中央—己方”三个位置间移动。按一次 W / S 或滚轮上 / 下切换一档，播放 220 毫秒快速平移动画；长按不重复触发，连续滚轮惯性合并为一次切换。支持触屏上下滑动。无总览、滚动条和镜头切换按钮；选牌、结束回合不改变镜头，弹窗打开时暂停镜头输入。敌方来袭预告常驻视窗顶部。
- 五列、双方各前后两排。普通生物在前排攻击；后排使用远射、鼓舞等能力。每个新回合开始、部署之前，双方所有后排单位在同列前排为空时自动上前；战斗中不即时补位。此规则不需要印记，原“接替”印记已移除。
- 结束回合：我方按列从左到右、同列后排先于前排攻击 → 预告敌人入场 → 敌方同样结算 → 新回合恢复一次抽牌机会。敌方无需献祭，每回合最多部署一只（包括归魂返场）；多余预告顺延。
- 动画串行播放：手牌飞入并拍落、敌方入场、攻击前冲、受击震动与伤害数字、死亡与献祭退场、回合开始上前补位。上一动作完成后才提交对应状态并播放下一动作；结算时锁住部署与结束回合。侧栏显示当前动作，支持系统减少动态效果设置。
- 攻击瞬间同列前排为空，才直接推动天平（即使后排有单位）。前排承伤后的溢出伤害施加到同列后排；后排为空或伤害仍有剩余时，均不推动天平。双方伤害推动同一天平，每场归零，向任一方倾斜达到 10 点时该方立即失败。
- 获胜三选一拿牌或跳过，返回地图继续选路；Boss 胜利通关，失败结束本局。
- 转移印记仅在地图节点进行，每节点一次，供体永久消耗。外来容量为 3，可覆盖旧外来印记，至少保留 6 张牌。
- 死亡原因区分被击杀与被献祭：两者都会触发归魂，献祭不会触发荆棘。归魂返回手牌，重新召唤仍需献祭；两个牌堆均耗尽后，每个新回合受到递增疲劳伤害。

- 黑山羊：1 费、0 攻 / 1 血，丰饶祭品印记使其提供 3 费，超额不保留。
- 实验生物：2 费、0 攻 / 1 血，永续祭品印记使其献祭后保留位置、血量和印记，不触发死亡；每次召唤只能计费一次，可再次用于其他召唤。满场且所选祭品均存活时仍停留在标记阶段，需选一个会腾出空位的祭品或取消。
- 新生物加入初始牌组和奖励池，两种印记均可在工坊转移。启动时用系统时间初始化地图种子；同一局旅程沿用种子，刷新应用生成新种子。洗牌、敌方入场列和三选一奖励使用独立随机序列，重复渲染不消耗随机数。

## 原型范围

### 费用与身材基准

身材以攻击 / 生命表示。1 费基准为 1/2 或 2/1；2 费基准为 3/3，可按定位调整为 4/2 或 2/4；3 费是常规最高费用，基准为 5/6，可偏向 6/5 或 4/7。献祭需要放弃已有场面，所以高费收益采用递增曲线，不按费用简单线性增长。

印记占用部分身材强度，不能只按攻血总和定价。远射提供后排输出，分袭最多打两列；归魂、丰饶祭品和永续祭品主要按资源价值评估。外来印记容量是工坊约束，不是费用的换算公式。

| 生物 | 费用 | 攻击 / 生命 | 定位 |
| --- | --- | --- | --- |
| 松鼠 | 0 费 | 0/1 | 基础祭品 |
| 赤尾狐 | 1 费 | 2/1 | 标准进攻生物 |
| 铁背甲虫 | 1 费 | 1/2 | 硬甲防御，降低攻击换取抵御小伤害的能力 |
| 归魂蛾 | 1 费 | 1/1 | 牺牲身材换取归魂 |
| 黑山羊 | 1 费 | 0/1 | 一次性提供 3 费，易被击杀 |
| 苔原狼 | 2 费 | 3/3 | 标准中坚 |
| 枝角鹿 | 2 费 | 1/4 | 后排鼓舞辅助 |
| 夜巡鸮 | 2 费 | 2/2 | 远射换取安全输出位置 |
| 实验生物 | 2 费 | 0/1 | 可持续提供费用，提高启动成本 |
| 山脊熊 | 3 费 | 5/6 | 荆棘重型前排，能迅速击穿低费防线 |
| 裂风鹭 | 2 费 | 2/3 | 分袭过渡单位；3 费金雕为 4/5、飞行＋分袭 |

这是一轮初始平衡校准；敌我共用基础卡牌数值，敌方每回合最多召唤一只的限制保持不变。规则测试验证结算正确性，实战平衡仍需试玩调整。

55 张基础牌、30 种印记、6 种衍生物、14 张初始主牌组，敌人随回合从低费逐步扩展到高费。数值为试验值，未做长期平衡。使用献祭付费及双牌堆抽牌，包含 18 层分叉地图，暂无存档；刷新页面会重置。精英及 Boss 有独立配置，均使用同一天平阈值。Google Fonts 不可用时使用本机字体。

## 文件

- `src/random.ts`：地图种子、确定性随机数生成器与洗牌工具。
- `src/game.ts`：卡牌模板、印记权重、战斗状态及纯规则函数。调整数值从此处开始。
- `src/App.tsx`：冒险与战斗切换、串行动画、结算和规则手册。
- `src/adventure.ts`：地图生成、节点状态机、选牌、风险强化及隐藏效果。
- `src/AdventureView.tsx`：分叉地图和节点交互。
- `src/BattleView.tsx`、`src/BattleView.css`：全屏战斗布局与操作。
- `src/BattleCamera.css`：战场镜头、统一卡牌比例和等比卡面排版。
- `src/battleAnimation.tsx`、`src/BattleAnimation.css`：Web Animations API 动作播放与卡牌飞行层。
- `src/Cards.tsx`：共享卡面和右键查看入口。
- `src/Creature.tsx`：原创 SVG 生物徽记。
- `src/App.css`：页面和响应式样式。
- `tests/game.test.mjs`：容量覆盖、重复转移、战斗站位、归魂、胜负与疲劳测试。

## 种族卡池与新能力

基础卡池为 **55 张**：兽类 14、鸟类 12、虫族 12、爬行类 11、蛛类 4、特殊生物 2。费用分布为 0 费 14、1 费 25、2 费 12、3 费 4。另有 6 种仅由效果生成的衍生物。完整清单见 [卡池与印记](docs/card-pool.md)，也可以访问 `/creatures` 按种族、费用、名字和效果筛选。

- 初始主牌组仍为 14 张，加入田鼠、兔和蚂蚁三张零费生物以加快展开。奖励从除松鼠外的基础牌中抽取三种不同生物；衍生物不进入奖励池。
- 敌方种类也由地图种子控制，前三回合费用不超过 1，第 4–7 回合不超过 2，此后不超过 3。每回合最多部署一只，包括敌方的衍生物与归魂；多余卡进入预告队列。
- 飞行单位可从前后排攻击同列天空；该列没有有效飞行单位时直接攻击玩家。天空溢出只传给该列后方飞行单位，不命中地面，也不溢出到玩家。普通地面攻击仍能打到前排飞行单位。
- 结网压制同列敌方飞行，结网单位死亡后立即恢复。俯冲优先攻击该列非飞行后排；没有此目标时回到自身原本的攻击路线。分袭按列独立检查，连击每轮重新选目标。
- 正常行动顺序为后排到前排、从左到右；迁徙不会造成同回合重复行动。完成全部攻击后再处理短命或迁徙，短命优先。潜伏增强首次整轮攻击，连击的第二轮不再翻倍。
- 部署动画后依次结算搬运、筑巢，再检查对方前排的伏击。伏击执行一轮攻击（可以分袭），不因连击重复；伏击可以消耗潜伏并触发短命、迁徙。0 血单位在登场效果后自然死亡。
- 剧毒必须实际造成正伤害，毒杀不额外产生溢出。断尾可以抵挡致命攻击、剧毒与反伤，但不能阻止献祭或短命。蜂群在承受攻击且存活时触发，包括硬甲格挡；不会因献祭触发。
- 被击杀、献祭死亡、自然死亡分开标记。归魂与遗卵响应全部死亡；食腐只响应其他单位被击杀，吞食只响应自己的攻击击杀，攻击者同时死亡时不能吸血复活。
- 繁育、成长按每次登场触发一次；蜕变在存活两个新回合后触发。蛋先孵化为雏鸟，再等一个新回合成长。变形保留其他印记，归魂恢复本次登场时的卡牌形态，清除本次登场的强化和触发记录。
- 所有新增印记都可在工坊转移，强组合被保留，包括飞行＋分袭、剧毒＋分袭、归魂＋短命、归魂＋搬运、永续祭品＋丰饶祭品。

代码按职责分为 `src/cardData.ts`（卡池与说明）、`src/battleEngine.ts`（单次结算及触发）、`src/game.ts`（回合、部署、抽牌、献祭和奖励入口）。战斗动画使用相同结算生成的状态快照。
