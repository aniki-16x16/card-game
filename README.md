# 苔原契约 · Verdant Pact

在雾林中组建生物牌组，沿分叉地图冒险，并通过献祭与部署赢下战斗。每场战斗都会让双方的攻击推动同一架天平；击败荒野之王，完成旅程。

## 怎么玩

- 沿地图选择下一处目的地。你会遭遇普通战斗、精英和首领，也能在途中获得新牌、强化或整理牌组。
- 战斗时，每回合从主牌堆或松鼠牌堆抽一张牌。高费用生物需要献祭场上生物来支付费用，再部署到空位；松鼠等零费用生物可以直接部署。
- 结束回合后，双方生物依次攻击。留意卡牌的攻击、生命与印记，安排前后排和出牌顺序，让每次攻击都推动天平向有利方向倾斜。
- 天平向任一方倾斜到极限，该方就会落败。赢下战斗后可从奖励中挑选新牌，也可以跳过，随后继续旅程。
