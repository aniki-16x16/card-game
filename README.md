# 苔原契约 · Verdant Pact

React 19 + TypeScript + Vite 构建的单人卡牌 Web 原型。无需后端。深苔绿战术桌面、原创 SVG 生物徽记，适配桌面和窄屏。

## 运行

```sh
npm install
npm run dev
```

```sh
npm test       # Node.js 22.6+，核心战斗和印记规则测试
npm run build # TypeScript 检查及生产构建
npm run lint
```

## 试玩

- 选择手牌，标记己方场上单位献祭，每张提供 1 点费用。凑够费用前可撤销标记或取消；凑够立即移除祭品，随后必须选择空位部署，不能取消、换牌或结束回合。0 费单位跳过献祭。
- 松鼠为 0 攻 / 1 血、0 费。起手 3 张主牌加 1 张松鼠，独立松鼠牌堆共 10 张（起手后剩 9 张）。每回合可从主牌堆或松鼠牌堆抽取 1 张，共享次数且不累积；不再自动抽牌。
- 战场占据屏幕中央，手牌在底部居中，必要状态与操作位于两侧。右键手牌或场上生物可查看印记说明；关闭说明会保留当前选牌。触屏可选择手牌后使用“查看印记”，场上卡片也支持点击查看。
- 场上卡和手牌统一为 3:4，共用卡面排版。镜头默认居中，在“敌方—中央—己方”三个位置间移动。按一次 W / S 或滚轮上 / 下切换一档，播放 220 毫秒快速平移动画；长按不重复触发，连续滚轮惯性合并为一次切换。支持触屏上下滑动。无总览、滚动条和镜头切换按钮；选牌、结束回合不改变镜头，弹窗打开时暂停镜头输入。敌方来袭预告常驻视窗顶部。
- 五列、双方各前后两排。普通生物在前排攻击；后排使用远射、鼓舞等能力。每个新回合开始、部署之前，双方所有后排单位在同列前排为空时自动上前；战斗中不即时补位。此规则不需要印记，原“接替”印记已移除。
- 结束回合：我方按列从左到右、同列后排先于前排攻击 → 预告敌人入场 → 敌方同样结算 → 新回合恢复一次抽牌机会。敌方无需献祭。
- 动画串行播放：手牌飞入并拍落、敌方入场、攻击前冲、受击震动与伤害数字、死亡与献祭退场、回合开始上前补位。上一动作完成后才提交对应状态并播放下一动作；结算时锁住部署与结束回合。侧栏显示当前动作，支持系统减少动态效果设置。
- 攻击瞬间同列前排为空，才直接扣对方生命（即使后排有单位）。前排承伤后的溢出伤害施加到同列后排；后排为空或伤害仍有剩余时，均不扣生命。双方生命独立，每场重置。
- 获胜选择一张奖励卡，前往工坊改造后进入下一场；失败可重试或改造。
- 战前/战后工坊中选择供体、受体和一个印记，供体被消耗。外来印记容量为 3，天生印记不占容量。允许反复转移和覆盖旧印记，牌组至少保留 6 张。进入战场前可撤销上次转移。
- 死亡原因区分被击杀与被献祭：两者都会触发归魂，献祭不会触发荆棘。归魂返回手牌，重新召唤仍需献祭；两个牌堆均耗尽后，每个新回合受到递增疲劳伤害。

## 原型范围

8 种主牌生物加松鼠、6 种印记、12 张初始主牌组、固定牌序与敌方入场计划。数值为试验值，未做长期平衡。使用献祭付费及双牌堆抽牌，无地图或存档；刷新页面会重置。胜利后的遭遇持续推进，敌方生命随场次提高。Google Fonts 不可用时使用本机字体。

## 文件

- `src/game.ts`：卡牌模板、印记权重、战斗状态及纯规则函数。调整数值从此处开始。
- `src/App.tsx`：战斗界面、印记工坊、奖励和规则手册。
- `src/BattleView.tsx`、`src/BattleView.css`：全屏战斗布局与操作。
- `src/BattleCamera.css`：战场镜头、统一卡牌比例和等比卡面排版。
- `src/battleAnimation.tsx`、`src/BattleAnimation.css`：Web Animations API 动作播放与卡牌飞行层。
- `src/Cards.tsx`：共享卡面和右键查看入口。
- `src/Creature.tsx`：原创 SVG 生物徽记。
- `src/App.css`：页面和响应式样式。
- `tests/game.test.mjs`：容量覆盖、重复转移、战斗站位、归魂、胜负与疲劳测试。
