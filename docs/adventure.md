# 冒险流程

地图由启动时的系统时间种子生成。地图结构、节点类别选项、卡牌奖励、强化属性和风险判定各自使用独立随机序列，不受渲染或动画次数影响。新开一局使用新种子；当前未接存档。

主进程 18 层，通常三路，局部最多五个节点，每个节点最多三个出口。第 5、9、13、17 层交汇。第 1 层拿牌，第 17 层强化，第 18 层 Boss。左侧倾向补牌，右侧倾向精简与改造。第 6、12 层可选精英，后接一个独占的额外强化或转移节点，再汇回普通路线。普通路线走 18 个节点，两次精英路线最多 20 个。道具节点类型已预留，但不参与生成。

费用、种族节点先给三个不同类别，选定后给三张不同卡牌。类别不能重选，拿牌可跳过。种族选项只从至少有三种可奖励生物的种族中抽取；松鼠始终来自独立牌堆。战斗与精英奖励相同。删卡和转移每节点只能执行一次，需保留至少六张牌。

强化节点进入时固定攻击 +1 或生命 +2。每次访问只能强化同一张牌，最多三轮，失败率依次为 0、1/6、1/3。成功后可以立即带走；失败永久移除卡牌，属于局外消耗，不触发战斗死亡效果。同一张牌在后续节点可再次强化。

隐藏机制：`species === 'viper'` 的蝰蛇（1 费 0/1、无印记）被吃掉后，强化者死亡，该局所有后续强化永久安全。不是按卡牌实例 ID 或剧毒印记判断；三轮上限仍然保留，新局恢复风险。玩家卡面不透露此机制。

天平每场从零开始，我方直接伤害为正、敌方为负，双方伤害抵消。达到 +10 胜利，达到 -10 失败，逐次攻击立即判断，结束后不再执行后续攻击。单位伤害与溢出不直接改变天平；双牌库耗尽后的递增疲劳向我方推动天平。

敌方每回合最多部署一只。普通敌军随回合从低费扩展；精英起始可使用二费单位且生命 +1；Boss 可使用三费单位、生命 +1，奇数回合预告单位获得硬甲，偶数回合获得飞行。配置可继续平衡，天平阈值相同。

战斗胜利 → 普通奖励 → 地图；Boss 胜利 → 通关结算。失败结束本局，不开放免费工坊或重复领奖。局外强化和印记保留在主牌组，战斗伤势与临时增益不带回主牌组。
